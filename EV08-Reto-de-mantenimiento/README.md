# Sistema de inventario

Proyecto base de la actividad AA3-EV08. Permite consultar productos, ver el detalle de un registro y abrir el formulario de registro.


## Pantallas

- Inicio
- Listado de productos
- Registro de producto
- Detalle de producto


## Correcciones y nuevas funcionalidades (AA3-EV08)

- Se corrigieron los errores de HTML, CSS y JavaScript del proyecto base (enlaces, IDs, labels, tipos de campo, orden de columnas, media query).
- **Búsqueda de productos:** campo de texto con botones "Buscar" y "Limpiar" en el listado.
- **Edición de productos:** botón "Editar" por fila; carga los datos en el formulario, valida y actualiza el listado.
- **Filtro por estado:** selector Todos / Activos / Inactivos con contador de registros.
